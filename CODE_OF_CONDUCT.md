# Código de Conduta

Trate participantes com respeito. Discuta o código e os efeitos da mudança, sem ataques pessoais. Acolha dúvidas de usuários não técnicos. Seja claro sobre riscos, limitações e o que realmente foi medido.

Não são aceitos assédio, discriminação, ameaças, publicação de dados pessoais, intimidação ou pressão para desativar proteções do Windows. Não publique informações de vulnerabilidades ou credenciais em discussões públicas.

Mantenedores podem editar/remover conteúdo impróprio, encerrar discussões, restringir participação ou bloquear reincidências, considerando contexto e gravidade. Não há promessa de atendimento imediato.

Para abuso na plataforma, use o [relato de abuso do GitHub](https://github.com/contact/report-abuse). Para uma vulnerabilidade no aplicativo, use o [canal privado de segurança](SECURITY.md). Não exponha detalhes pessoais para relatar uma ocorrência.
