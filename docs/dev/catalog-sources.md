# Fontes do catálogo — revisão de 31/10/2026

68 de 86 itens com identidade/mapeamento documentados; 58 de 73 itens de nível 1/2 verificados.

`verified` significa que a identidade ou o mapeamento tem fonte primária, não que o ajuste melhora jogos. Aplicabilidade, risco, `automatic`, edição e build continuam separados. A presença real é detectada antes de qualquer operação.

As fontes VDOT são dados do projeto expressamente referenciado pela [documentação Microsoft](https://learn.microsoft.com/en-us/windows-server/remote/remote-desktop-services/remote-desktop-services-vdi-optimize-configuration). A referência é fixada por commit. O guia trata de VDI, não de jogos; não copiamos suas recomendações de desativação. Para Appx, ele só confirma o nome do pacote. Fontes Q&A, fóruns e otimizadores de terceiros não foram aceitas como verificação.

Home: nenhuma política de Windows restrita a Pro/Enterprise/Education é selecionada. Políticas de navegador Edge e serviços não são políticas MDM de Windows; os itens presentes podem ser selecionados conforme suas restrições. Appx permanece exclusivamente manual em todas as edições. Inicialização é sempre manual e StartupApproved continua não documentado como API pública.

Recall: a [Microsoft documenta](https://learn.microsoft.com/en-us/windows/client-management/mdm/policy-csp-windowsai#disableaidataanalysis) a exclusão de snapshots ao habilitar DisableAIDataAnalysis. O alvo continua no inventário, mas está bloqueado, marcado manual e alto risco. Não confundir restaurar configuração com recuperar dados.

## Contratos usados pelos executores

- [Get-AppxPackage](https://learn.microsoft.com/en-us/powershell/module/appx/get-appxpackage): inventário; AllUsers requer elevação
- [Remove-AppxPackage](https://learn.microsoft.com/en-us/powershell/module/appx/remove-appxpackage): remoção de usuários e tratamento de bundles
- [Remove-AppxProvisionedPackage](https://learn.microsoft.com/en-us/powershell/module/dism/remove-appxprovisionedpackage): provisionamento é separado dos usuários existentes
- [Store URI](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-store-app): PFN ainda suportado, porém descontinuado; ProductId é a recomendação atual. Implementado o PFN pedido, sem alegar disponibilidade futura
- [Checkpoint-Computer](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.management/checkpoint-computer?view=powershell-5.1): limite diário
- [Powercfg](https://learn.microsoft.com/en-us/windows-hardware/design/device-experiences/powercfg-command-line-options): plano ativo, duplicação, consulta e exclusão
- [Run/RunOnce](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys): Run é documentado; o formato StartupApproved 02/03 continua experimental e somente manual
- [WTSQuerySessionInformation](https://learn.microsoft.com/en-us/windows/win32/api/wtsapi32/nf-wtsapi32-wtsquerysessioninformationw): usuário da sessão do processo, inclusive sob UAC com outra conta
- [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0.txt): texto oficial aplicado a LICENSE

- [GetOwnerSid local](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/getownersid-method-in-class-win32-process): SID do shell canônico da sessão, sem consulta de nome em domínio
