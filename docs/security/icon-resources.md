# Ícones de jogos — leitura limitada

A única extensão nativa da Entrega 2 é `games_action` com variante tipada `icons` sem parâmetros. O backend carrega a biblioteca validada e resolve os IDs/caminhos já cadastrados. A UI não envia caminho, script, comando ou PID para extrair um ícone. `local_executable` rejeita rede/junções/links, exige arquivo local e canonicaliza. A fronteira também exige caminho de unidade local e extensão EXE. Falha de leitura resulta em ícone geométrico, nunca execução alternativa.

O Shell extrai um recurso com [ExtractIconExW](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/nf-shellapi-extracticonexw); GDI desenha em bitmap próprio fixo de 32×32. Apenas esses pixels são codificados como PNG/base64 e entregues como data URI, permitido pela CSP existente. Não há LoadLibrary do arquivo, OpenProcess, hook nem alteração no arquivo. Todos os handles GDI/HICON são próprios e liberados por RAII, inclusive nos erros. Duas linhas de blocos unsafe constam no inventário com hashes e comentários SAFETY. O monitor de jogos não chama esta API.

A UI consulta os ícones uma vez por conjunto de jogos, sem repeti-los no polling de status. Cada biblioteca aceita até 128 jogos; cada imagem tem 4096 bytes de pixels antes da compressão. Os ícones Appx usam iniciais quando o inventário somente leitura não fornece uma imagem confiável; não ampliamos o acesso do inventário ou lemos dados de outros usuários para isso.

Fontes adicionais: [DrawIconEx](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-drawiconex), [CreateDIBSection](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-createdibsection). Validação em Linux testa recusa de caminhos; Windows testa codificação limitada. O probe `cargo run --release -p ametista-windows-runtime --example icon_probe --locked --offline` extrai somente o recurso do nosso `target/release/ametista.exe`, confere o PNG 32×32 e salva evidência em work. Ele passou neste host e faz parte do CI Windows. Ícones de jogos variados e DPI alto ainda precisam de aceite manual em VM.
